# Netflix Data Cleaning & Preparation Using Python

## Project Overview

This project performs a complete **Netflix Data Cleaning & Preparation** workflow using **Python and Pandas**.

The purpose of this project is to clean, standardize, and prepare the Netflix Movies and TV Shows dataset for further analysis and visualization.

---

## Workflow

The project follows five main steps:

1. Import the Netflix dataset using Python and Pandas.
2. Identify and handle missing values.
3. Remove duplicate records and formatting inconsistencies.
4. Standardize Country, Rating, and Type.
5. Export the cleaned dataset for further analysis.

---

## Technologies Used

- **Python**
- **Pandas**
- **CSV**
- **PyCharm IDE**

## Dataset

The project uses the commonly used **Netflix Movies and TV Shows dataset**:

`netflix_titles.csv`

The original dataset contains:
